# BOROO — Миний бүтээлийн тал нутаг

2026-10-15 · Загварын баримт · Хэрэгжүүлэхийн өмнөх хяналт

## Зорилго
Boroo-ийн хийсэн вэбсайт, Windows software-уудыг Монгол тал нутагт морь унаж аялдаг өнгөлөг 3D portfolio-оор танилцуулна. Bruno Simon-ийн ертөнцөөр аялах санаанаас урам авч, өөрийн дүр, газар нутаг, загвар болон код бүтээнэ. Сайтын хэрэглэгчид GitHub/repository холбоос үзүүлэхгүй.

## Харагдах байдал
Ногоон тал, алсын намхан уул, хөх тэнгэр, бөөрөнхий үүл, зам, гэрүүд, овоо, чулуу, адуу бүхий stylized low-poly ертөнц. Дулаан гэрэлтүүлэг, зөөлөн сүүдэр, уншихад цэвэр интерфэйстэй. Дээлтэй морьтон төв дүр байна. Геометрээр бүтээсэн морь, хүн эхний хувилбарт ашиглана; гаднын asset лицензээс хамаарахгүй. Морь хөл, хүзүү, сүүлний хөдөлгөөнтэй, морьтон хөдөлгөөн дагаж зөөлөн савлана. Бодит морин хөдөлгөөний нарийвчилсан simulation амлахгүй.

## Аялал ба удирдлага
Эхлэх дэлгэцэд нэр, нэг өгүүлбэр танилцуулга, «Аяллаа эхлэх», «Бүтээлүүд үзэх» байна. WASD/сум хөдөлгөж, Shift давхиулна. Камер араас дээрээс зөөлөн дагана. Утсанд joystick, үйлдлийн товч байна. Дэлгэцийн заавар эхний удаад үзэгдэнэ. Зам, өртөө болон ертөнцийн хил тодорхой байна; гэр, том чулууг нэвтрэхгүй. Ойртоход өртөө тодорч, E/товшиход танилцуулга нээгдэнэ. Цонх нээлттэй үед морь зогсоно, Escape хаана, focus буцна.

## Бүтцийн санал
Төв гэр: миний тухай. Зэргэлдээ хоёр бүс: вэб бүтээлүүд, desktop хэрэгслүүд. Өртөө бүр өөрийн өнгө болон жижиг байгууламжтай. Дээрх цэс: Бүтээлүүд, Миний тухай, Газрын зураг, MN/EN, Дуу. Жижиг газрын зураг дээр одоогийн байрлал, өртөөнүүд харагдана. Цэсээс өртөө сонгон очих болон бүх бүтээлийг шууд жагсаалтаар үзэх боломжтой.

## Бүтээлийн контент

README нь live ажиллагааны баталгаа биш. Зураг байхгүй бол төслийн нэртэй график үзүүлж, бодит screenshot мэтээр танилцуулахгүй.

Тийм байршилгүй бол татах товчийг нууж, software-ийн танилцуулгыг үлдээнэ. Repository болон эх кодын холбоос цэсэнд байхгүй.

## Танилцуулга ба холбоо
Дэлгэцийн нэр BOROO. Тайлбар нь software, AI хэрэгсэл, вэб бүтээл хийдэг тухай баримтад тулгуурласан байна. Имэйл, утас, олон нийтийн хаягийг тааж оруулахгүй. Хэрэглэгчийн өгсөн баталгаатай холбоо барих мэдээлэл байхгүй үед холбоо барих хэсэгт хоосон form эсвэл ажиллахгүй товч тавихгүй.

## Техникийн бүтэц
Vite + TypeScript + Three.js, статик build. World, horse/rider, input, movement/collision, camera, interaction, UI/i18n, project-data модулиуд тусдаа байна. Контент нэг typed өгөгдлийн сангаас өртөө болон жагсаалтад гарна. Сервер, нэвтрэлт, төлбөр шаардахгүй. Dependency хувилбарыг хэрэгжүүлэх үед баталгаажуулж lockfile хадгална. Asset-ууд өөрийн procedural геометр эсвэл лиценз нь шалгагдсан файл байна.

## Хүртээмж ба гүйцэтгэл
3D-ээс үл хамаарах HTML бүтээлийн жагсаалт, гарын удирдлага, focus, dialog нэр, тод contrast байна. Reduced-motion үед камерын савлалт болон чимэг animation багасна. Дуу анхнаасаа унтраалттай; хэрэглэгч асаана. WebGL ажиллахгүй бол HTML жагсаалт автоматаар гарна. Pixel ratio болон сүүдрийн чанарыг хязгаарлаж, window нуугдахад render pause хийнэ. Resize, orientation change дэмжинэ. Зорилт: ердийн desktop-д 60fps, дэмжигдэх утсанд 30fps; бодит төхөөрөмж дээр хэмжээгүй бол батлагдсан гэж тайлагнахгүй.

## Баталгаажуулалт
Production build; хөдөлгөөний frame-rate independence, collision, өртөөний хүрээ, project URL schema болон орчуулгын түлхүүрийн утгатай unit checks. Боломжтой браузераар keyboard/touch, dialog/Escape/focus, цэс, газрын зураг, resize, fallback шалгана. Браузер QA боломжгүй бол хязгаарыг тодорхой тайлагнана. Нийтлэхийн өмнө гаднын холбоос болон суулгацын байршлыг шалгана. Үнэн зөв контент, морьтон удирдах, өртөө нээх, шууд жагсаалтаар үзэх нь хүлээн авах үндсэн шалгуур.

## Хүргэлт
Хувийн review сайт, эх код, build болон шалгалтын дүн. Хэрэглэгч тусдаа public нийтлэхийг хүсвэл үзэгчдийн тохиргоог өөрчилнө. Энэ баримтын дараа хэрэгжүүлэх төлөвлөгөө боловсруулна.

## Батлагдсан шинэчлэл — 2026-10-15
Хэрэглэгч бодит мэт TPS game дүрслэл, бодит газрын гадаргуу, чанартай 3D морь болон animation, морин хуурын хөгжим хүссэн. Энэ нь өмнөх low-poly/procedural морины шаардлагыг орлоно. Warhorse Lite PBR asset, idle/walk/canter хөдөлгөөн, Poly Haven PBR terrain, Oleg Yastrebov CC BY богино морин хуурын loop ашиглана. Уг морь European heavy warhorse төрхтэй; баталгаатай Монгол үүлдрийн модель биш. Морьтон нь одоогийн хувилбарт өөрийн geometry-оор бүтээсэн дээлтэй дүр; photoreal rigged хүний asset биш. AAA тоглоомын fidelity амлахгүй. Browser visual QA байхгүй тул дүрслэлийн эцсийн чанарыг баталгаажаагүй.
